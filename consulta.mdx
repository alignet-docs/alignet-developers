---
title: "Consulta de Transacciones"
---

## Flujo de Consulta

Para consultar una transacción previamente procesada, la aplicación debe invocar la función `startSearch` del objeto `PaymeClient`.

La consulta puede realizarse utilizando el número de operación del comercio y, opcionalmente, el identificador de transacción generado por Pay-me.

## Parámetros de Entrada

| Parámetro | Tipo | Descripción |
| :-- | :-- | :-- |
| `from` | Activity | Activity desde donde se realizará la invocación del SDK. |
| `merchantOperationNumber` | String | Número de operación o pedido que se desea consultar. |
| `transactionID` | String? | Identificador único de la transacción generado por Pay-me. Este parámetro es opcional. |
| `delegate` | Activity | Activity encargada de implementar los métodos del delegado. |

<Check>
  La consulta puede realizarse utilizando únicamente el número de operación `merchantOperationNumber`). El parámetro `transactionID` es opcional.
</Check>

## Ejemplo de Invocación

```text
private fun invokeForConsult() {
    val operationNumber = this.binding.inputOperationNumber.text.toString()

    PaymeClient.startSearch(
        from = this,
        merchantOperationNumber = operationNumber,
        transactionID = null,
        delegate = this
    )
}
```

## Recepción de la Respuesta

Para recibir el resultado de la consulta, se debe implementar el método `onSearchResponse`.

```text
override fun onSearchResponse(response: PMSearchResponse) {
    val gson = GsonBuilder().setPrettyPrinting().create()
    val gsonResponse = gson.toJson(response)

    val intent = Intent(this, ResponseActivity::class.java).apply {
        putExtra("ACTION", this@RequestActivity.action)
        putExtra(
            "REQUEST_PAYME",
            "Número de pedido: ${binding.inputOperationNumber.text}"
        )
        putExtra("RESPONSE_PAYME", gsonResponse)
    }

    startActivity(intent)
    finish()
}
```

## Respuesta de Consulta

El resultado de la consulta será devuelto mediante el objeto `PMSearchResponse`.

<Info>
  La información retornada en `PMSearchResponse` puede incluir una o varias transacciones asociadas al número de operación consultado.
</Info>
