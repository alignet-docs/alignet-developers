---

El SCC o sistema de caja inicia un cobro mediante Pay-me PinPAD y espera el resultado en la misma llamada.

```http
POST /authorize
Content-Type: application/json
```

URL completa:

```text
http://<IP_DEL_PINPAD>:<PUERTO>/authorize
```

## Cuerpo de la solicitud

```json
{
  "operationNumber": "44992528",
  "amount": 100,
  "currency": 604,
  "additionalFields": {
    "plate": "ABC-123",
    "tollPointId": "PEAJE-01",
    "laneId": "VIA-03"
  }
}
```

## Campos

| Campo | Tipo JSON aceptado | Obligatorio | Validación | Descripción |
| --- | --- | --- | --- | --- |
| `operationNumber` | String | Sí | Entre 1 y 64 caracteres, sin espacios. | Identificador único generado por el SCC. Funciona como clave de idempotencia y referencia de consulta. |
| `amount` | Number o String | Sí | Entero positivo de 1 a 12 dígitos, expresado en unidades menores. | Monto total del cobro. `1500` o `"1500"` representan S/ 15.00. |
| `currency` | Number o String | No | Código numérico ISO 4217 de exactamente 3 dígitos. | Moneda del cobro. Si se omite, Pay-me PinPAD utiliza `604` (PEN). |
| `additionalFields` | Object | No | Todas las claves deben tener valores String. | Información complementaria asociada al cobro. |

## Reglas de validación

### `operationNumber`

- Genéralo en el SCC antes de enviar la solicitud.
- Persístelo antes del `POST` para poder recuperar el resultado.
- Usa un valor nuevo para cada operación real de cobro.
- No uses espacios ni excedas 64 caracteres.
- Reutiliza exactamente el mismo valor si necesitas recuperar o reenviar una solicitud cuyo resultado no recibiste.

<Warning>
  No generes un nuevo `operationNumber` después de un timeout. La primera solicitud puede haber producido un cargo.
</Warning>

### `amount`

El monto no admite decimales ni separadores. Convierte el importe a unidades menores:

| Importe | Valor válido de `amount` |
| --- | ---: |
| S/ 1.00 | `100` |
| S/ 8.50 | `850` |
| S/ 15.00 | `1500` |
| S/ 125.40 | `12540` |

Pay-me PinPAD acepta el valor como número JSON o cadena numérica. Para simplificar el contrato de tu cliente, utiliza una representación de forma consistente.

### `currency`

Para soles peruanos utiliza `604` o `"604"`. Si omites el campo, la aplicación utiliza `604`.

La habilitación de monedas distintas de PEN debe confirmarse con Alignet antes de producción.

### `additionalFields`

Todos los valores deben ser texto:

```json
{
  "additionalFields": {
    "plate": "ABC-123",
    "tollPointId": "PEAJE-01",
    "laneId": "VIA-03"
  }
}
```

No envíes números, booleanos, arreglos, objetos anidados ni valores `null` dentro de `additionalFields`.

<Note>
  La versión vigente confirma que `additionalFields` admite pares clave/valor de texto, pero no confirma un catálogo obligatorio ni el uso final de claves como `plate`, `tollPointId` o `laneId` por el procesador. Acuerda las claves de negocio con Alignet. Si no las necesitas, omite el objeto.
</Note>

## Ejemplo mínimo

```json
{
  "operationNumber": "44992528",
  "amount": 100
}
```

En este ejemplo, Pay-me PinPAD aplica la moneda predeterminada `604`.

## Ejemplo completo con cadenas numéricas

```json
{
  "operationNumber": "PEAJE01-20260827-000001",
  "amount": "1500",
  "currency": "604",
  "additionalFields": {
    "plate": "ABC-123",
    "tollPointId": "PEAJE-01",
    "laneId": "VIA-03"
  }
}
```

## Solicitud inválida

Una validación fallida devuelve HTTP `400` y no debe tratarse como un rechazo financiero:

```json
{
  "status": "ERROR",
  "resultCode": "BAD_REQUEST",
  "resultMessage": "amount inválido: debe ser un entero positivo en unidades menores"
}
```

Corrige el campo indicado antes de reenviar y registra el intento para mantener trazabilidad. La guía vigente no especifica el tratamiento de una misma referencia cuando cambia el payload; evita modificar monto o moneda para una referencia ya enviada.

## Antes de enviar

<Check>
  `operationNumber` está persistido, es único, tiene de 1 a 64 caracteres y no contiene espacios.
</Check>

<Check>
  `amount` contiene un entero positivo de hasta 12 dígitos en unidades menores.
</Check>

<Check>
  `currency`, si está presente, contiene exactamente tres dígitos.
</Check>

<Check>
  Todos los valores de `additionalFields`, si está presente, son cadenas.
</Check>

<Check>
  La solicitud usa `Content-Type: application/json` y un timeout HTTP de al menos 100 a 110 segundos.
</Check>
