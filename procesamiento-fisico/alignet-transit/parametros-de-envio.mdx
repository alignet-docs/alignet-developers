El SCC inicia la autorización mediante el Componente Local de Integración instalado en el P5L.

```http
POST /api/v1/payments
```

La URL base está sujeta a validación final durante la habilitación del ambiente.

## Headers

```http
Content-Type: application/json
Accept: application/json
```

## Campos de la solicitud

| Campo | Tipo | Requerido | Descripción | Ejemplo |
| --- | --- | --- | --- | --- |
| `operationNumber` | String | Sí | Identificador único de la operación generado por CELSAT. | `OP-20260821-000001` |
| `amount` | String | Sí | Cadena numérica que representa el monto en unidades menores, sin separador decimal. | `"1500"` equivale a S/ 15.00 |
| `currency` | String | Sí | Código numérico ISO 4217 de la moneda. | `604` para PEN |
| `additionalFields` | Object | No | Contenedor de información complementaria asociada a la operación. | Ver [Información adicional](#información-adicional) |

Los tres primeros campos conforman el contrato mínimo de autorización. `additionalFields` amplía la información de negocio sin sustituir ni modificar `operationNumber`, `amount` o `currency`.

## Ejemplo mínimo

```json
{
  "operationNumber": "OP-20260821-000001",
  "amount": "1500",
  "currency": "604"
}
```

<Note>
  `amount` es un `String` cuyo contenido debe ser un número entero positivo. No incluyas símbolo de moneda, separador decimal ni separador de miles.
</Note>

## Información adicional

Para el flujo de CELSAT, `additionalFields` permite asociar el desglose de importes y el identificador de turno o vía a la misma operación de pago. Cuando se incluya este objeto, debe contener las tres claves acordadas.

| Campo dentro de `additionalFields` | Tipo JSON | Requerido dentro del objeto | Formato | Descripción |
| --- | --- | --- | --- | --- |
| `montoPeaje` | String | Sí | Decimal(12,2): hasta 10 dígitos enteros y 2 decimales | Importe correspondiente al peaje. |
| `montoDetraccion` | String | Sí | Decimal(12,2): hasta 10 dígitos enteros y 2 decimales | Importe correspondiente a la detracción. Usa `"0.00"` cuando no aplique. |
| `IdTurnoVia` | String | Sí | Máximo 50 caracteres | Identificador de turno o vía utilizado por CELSAT para conciliación. |

```json
{
  "operationNumber": "OP-20260822-000001",
  "amount": "1500",
  "currency": "604",
  "additionalFields": {
    "montoPeaje": "10.00",
    "montoDetraccion": "5.00",
    "IdTurnoVia": "TV-20260822-001"
  }
}
```

Las claves y los valores de `additionalFields` se envían como cadenas y los nombres distinguen mayúsculas de minúsculas. CELSAT debe conservar exactamente `montoPeaje`, `montoDetraccion` e `IdTurnoVia`.

<Info>
  `amount` mantiene el formato de unidades menores: `"1500"` representa S/ 15.00. En cambio, `montoPeaje` y `montoDetraccion` utilizan representación decimal con dos posiciones. Los datos adicionales no reemplazan el importe total autorizado.
</Info>

Cuando CELSAT envía `additionalFields`, el Componente Local conserva esta información asociada a la transacción y la devuelve en `result.additionalFields` cuando la respuesta contiene datos de la operación. Esto permite mantener el mismo contexto en autorización, consulta y conciliación.

## Reglas de `operationNumber`

El SCC debe:

- generar un valor único para cada venta;
- persistirlo antes de enviar la solicitud;
- conservarlo hasta conocer el resultado final;
- no reutilizarlo para otra venta;
- mantener el mismo valor ante timeout o pérdida de comunicación;
- utilizarlo para consultar la operación cuando el resultado sea incierto.

```text
1 venta = 1 operationNumber
```

## Representación del monto

`amount` expresa el total que el P5L debe procesar en unidades menores de la moneda.

| Importe | `amount` |
| --- | ---: |
| S/ 8.50 | `"850"` |
| S/ 15.00 | `"1500"` |
| S/ 125.40 | `"12540"` |

El cálculo del importe corresponde al SCC. El P5L procesa el valor recibido y no requiere que CELSAT conozca las estructuras internas de PaymePOS SDK.

## Validaciones antes del envío

Antes de realizar el `POST`, verifica que:

- `operationNumber` sea una cadena no vacía y corresponda a una única venta;
- `amount` sea una cadena numérica que represente un entero positivo en unidades menores;
- `currency` sea `"604"` para operaciones en soles;
- si incluyes `additionalFields`, sus claves respeten la capitalización documentada y sus valores sean cadenas con el formato indicado;
- la solicitud use `Content-Type: application/json`;
- la referencia ya se encuentre almacenada para una posible recuperación.
