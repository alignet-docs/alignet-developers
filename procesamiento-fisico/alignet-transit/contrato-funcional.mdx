Esta página describe el contenido funcional intercambiado entre el SCC de CELSAT y el Componente Local de Integración. La especificación versionada de la interfaz formaliza el transporte, la serialización, los schemas, las longitudes y el catálogo de códigos.

## Solicitud de pago

| Dato funcional | Referencia | Regla | Ejemplo funcional |
| --- | --- | --- | --- |
| Referencia CELSAT | `operationNumber` | Identifica una única operación lógica dentro del comercio. | `20100008` |
| Punto de peaje | `tollPointId` | Código estable procedente del maestro acordado. | `PN005` |
| Carril | `laneId` | Código estable asociado al punto de peaje. | `L03` |
| Monto | `amount` | Entero en unidades menores. | `850` para S/ 8.50 |
| Moneda | `currency` | Código numérico `604` para PEN. | `604` |
| Fecha del evento | `eventDateTime` | ISO 8601 con zona horaria. | `2026-08-17T14:26:00-05:00` |
| Categoría vehicular | `vehicleCategory` | Valor del catálogo coordinado. | `<CATEGORIA>` |
| Sentido del carril | `laneDirection` | Valor del catálogo coordinado. | `<SENTIDO>` |

<Info>
  El ejemplo representa el contenido funcional. Los nombres, tipos, obligatoriedad condicional y envoltura corresponden a la versión de interfaz acordada.
</Info>

## Validaciones del SCC

Antes del envío, CELSAT debe verificar que:

- la referencia esté presente y no haya sido utilizada para otra operación lógica;
- peaje y carril pertenezcan al maestro habilitado;
- el monto sea un entero positivo en unidades menores;
- `currency` sea `604`;
- la fecha incluya zona horaria;
- categoría y sentido pertenezcan a los catálogos configurados;
- la misma referencia no se reutilice con datos diferentes.

## Respuesta funcional

| Dato | Disponibilidad | Uso de CELSAT |
| --- | --- | --- |
| `operationNumber` | En toda respuesta correlacionable. | Relacionar la respuesta con el evento del carril. |
| `transactionId` | Cuando Alignet haya asignado el identificador. | Soporte, seguimiento y conciliación. |
| `requestStatus` | En toda respuesta. | Distinguir recepción, validación, proceso, cancelación o finalización. |
| `result` | Cuando exista una decisión operativa. | Aplicar `PASS` o `NO_PASS` conforme a la política del carril. |
| `reasonCode` | Cuando el estado o resultado requiera una razón. | Diagnóstico y tratamiento funcional. |
| `amount` y `currency` | Cuando la solicitud haya sido reconocida. | Validar la operación correlacionada. |
| `brand` | Cuando se encuentre disponible y habilitado. | Comprobante y registro operativo. |
| `lastFourDigits` | Cuando se encuentre disponible y permitido. | Comprobante con dato enmascarado. |

## Dimensiones de estado

Reglas de interpretación:

- una solicitud aceptada no equivale a `PASS`;
- un estado en proceso no autoriza a abrir la barrera;
- `PASS` no se deriva directamente de un código financiero aislado;
- un timeout o una respuesta ausente no equivalen a `NO_PASS`;
- un valor desconocido se registra sin asumir su semántica y activa el flujo de recuperación;
- `operationNumber` y `transactionId` son identificadores diferentes.

## Credenciales y parámetros de ambiente

| Parámetro | Finalidad | Gestión |
| --- | --- | --- |
| `client_id` | Identificar al cliente de integración. | Alignet lo proporciona mediante un canal seguro. |
| `client_secret` | Autenticar el acceso correspondiente. | Se protege y rota según la política del ambiente. |
| `merchant_code` / MID / `idComercio` | Delimitar el comercio y el ámbito transaccional. | Alignet lo configura para el ambiente. |
| `TID` | Identificar el terminal. | Alignet lo asocia con el P5L y la ubicación operativa. |

No incluyas credenciales en código fuente, repositorios, logs funcionales, comprobantes ni mensajes de soporte.

## Comprobante

CELSAT genera e imprime el comprobante. La respuesta puede proporcionar `operationNumber`, `transactionId`, estado, decisión operativa, razón, monto, moneda, marca y últimos cuatro dígitos cuando estos datos se encuentren disponibles y su uso esté permitido.

El formato y los campos mostrados se coordinan entre ambas partes y deben respetar las reglas de seguridad aplicables.
