## Matriz de responsabilidades

| Área | CELSAT | Alignet | Coordinación |
| --- | --- | --- | --- |
| SCC y lógica del carril | Calcular el importe, generar la referencia, incorporar la información adicional acordada, invocar la interfaz y aplicar la política operativa. | Entregar una respuesta normalizada y documentada. | Validar el comportamiento de extremo a extremo. |
| Interfaz LAN | Implementar el cliente HTTP/JSON y gestionar la recuperación. | Proporcionar el Componente Local y los parámetros del ambiente. | Verificar conectividad y timeouts. |
| Componente Local | Consumir únicamente la interfaz documentada. | Instalar, configurar y operar el agente dentro del P5L. | Ejecutar pruebas de contrato. |
| PaymePOS SDK | No requiere integración directa. | Administrar inicialización, invocación y ciclo transaccional. | Validar códigos locales y comportamiento del terminal. |
| SDK y hardware del P5L | No requiere integración directa. | Administrar la interacción con el medio de pago y el dispositivo. | Validar escenarios físicos de prueba. |
| Plataforma de pagos | No requiere integración directa. | Procesar la autorización, asignar `transactionID` y normalizar la respuesta. | Correlacionar evidencias cuando sea necesario. |
| Idempotencia | Generar, persistir y no reutilizar `operationNumber`. | Permitir la recuperación mediante la referencia recibida. | Probar timeouts y duplicidad. |
| Trazabilidad | Registrar solicitud, respuesta y decisión del carril. | Mantener trazabilidad transaccional para soporte. | Definir evidencia y retención. |

## Preparación de CELSAT

### Cliente de integración

- Implementar `POST /api/v1/payments`.
- Implementar `GET /api/v1/payments/{operationNumber}`.
- Enviar y recibir JSON.
- Manejar `result` como objeto o `null`.
- Interpretar todos los estados y códigos documentados.
- Persistir las operaciones antes del envío.
- Recuperar operaciones abiertas después de una desconexión o reinicio.

### Lógica operativa

- Calcular el importe total antes de solicitar el pago.
- Representar el total como entero en unidades menores.
- Incorporar `montoPeaje`, `montoDetraccion` e `IdTurnoVia` dentro de `additionalFields` cuando corresponda.
- Confirmar el pago únicamente con `state = AUTORIZADO`.
- Mantener la operación abierta cuando `state = PENDIENTE`.
- Definir el comportamiento del carril para denegación, cancelación, expiración y error.
- No confundir una cancelación local con una denegación del emisor.

### Trazabilidad

- Registrar `operationNumber` y `transactionID`.
- Conservar `additionalFields` para conciliación cuando forme parte de la operación.
- Conservar códigos, mensajes, estado y razón.
- Registrar fecha y hora de envío, respuesta, consulta y recuperación.
- Excluir información sensible de tarjeta.

### Pruebas

- Disponer de un SCC de pruebas o simulador.
- Preparar referencias y montos controlados.
- Ejecutar escenarios de aprobación, denegación, cancelación, error y timeout.
- Conservar evidencia correlacionada por operación.

## Entregas de Alignet

Alignet proporciona:

- Componente Local de Integración instalado en el P5L;
- endpoints y contrato JSON documentados;
- PaymePOS SDK y SDK del dispositivo integrados en el terminal;
- procesamiento con la plataforma de pagos;
- respuesta normalizada con estados y códigos;
- ambiente y terminales P5L para las pruebas acordadas;
- parámetros de conexión sujetos a validación final;
- soporte y trazabilidad para la validación conjunta.

## Checklist de inicio

<Check>
  CELSAT identificó el proceso del SCC que consumirá la interfaz HTTP.
</Check>

<Check>
  El SCC puede generar y persistir un `operationNumber` único por venta.
</Check>

<Check>
  El SCC representa `amount` como una cadena numérica en unidades menores.
</Check>

<Check>
  El SCC puede construir y recuperar `additionalFields` con los valores asociados a la operación.
</Check>

<Check>
  La integración diferencia `success`, `resultCode` y `result.state`.
</Check>

<Check>
  El SCC puede consultar una operación después de timeout o reinicio.
</Check>

<Check>
  La conectividad LAN y los parámetros del ambiente se validarán con el P5L asignado.
</Check>

<Check>
  CELSAT dispone de datos y escenarios para las pruebas conjuntas.
</Check>
