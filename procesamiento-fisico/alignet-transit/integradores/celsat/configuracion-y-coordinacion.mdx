Esta página separa el contrato documentado de los parámetros que deben acordarse para cada ambiente. No implementes valores pendientes como si fueran parte estable de la API.

## Contrato documentado

| Elemento | Definición vigente |
| --- | --- |
| Cliente HTTP | SCC o sistema de caja. |
| Servidor HTTP | Aplicación Pay-me PinPAD en el Wiseasy P5L. |
| Transporte | HTTP/JSON sobre la red local. |
| Disponibilidad | `GET /health`. |
| Autorización | `POST /authorize`. |
| Consulta | `GET /payments/{operationNumber}`. |
| Cancelación o extorno | `POST /reversals`; interrumpe una autorización activa o extorna una venta aprobada según el estado actual. |
| Consulta de cancelación o extorno | `GET /reversals/{operationNumber}`. |
| Puerto | Configurable; valor predeterminado `8080`. |
| Solicitud | `operationNumber`, `amount`, `currency` y `paymentMethod` obligatorios; `additionalFields` opcional. |
| Moneda para PEN | `"604"`. |
| Aprobación | HTTP `200`, `status: "APPROVED"` y `resultCode: "00"`. |
| Recuperación | Consultar la misma referencia ante `202`, timeout o pérdida de conexión. |
| Idempotencia | Una referencia identifica una sola operación real de cobro. |
| Concurrencia | Una operación activa por terminal. |

## Configuración por terminal

Registra para cada Wiseasy P5L:

| Parámetro | Ejemplo | Responsable |
| --- | --- | --- |
| Identificador interno del terminal | `P5L-CARRIL-03` | Operación / Alignet |
| Carril o caja asociada | `VIA-03` | Integrador |
| Dirección IP | `192.168.68.121` | Administración de red |
| Puerto TCP | `8080` | Alignet / administración de red |
| Dirección MAC, si se reserva DHCP | Valor del terminal | Administración de red |
| Ambiente | Integración, UAT o producción | Alignet / integrador |
| Versión de Pay-me PinPAD | Versión entregada | Alignet |

No copies la IP de ejemplo en un ambiente real.

## Parámetros pendientes de confirmación

| Punto | Referencia disponible | Confirmación necesaria |
| --- | --- | --- |
| Espera interna de Pay-me PinPAD | 90 segundos en desarrollo. | Valor definitivo de producción. |
| Timeout del cliente | Al menos 100 a 110 segundos con la espera de referencia. | Valor definitivo, siempre superior al timeout del terminal. |
| Frecuencia de consulta | `Retry-After`; aproximadamente 2 segundos como referencia. | Intervalo, backoff y tiempo máximo de consulta. |
| Operación no resuelta | No iniciar otro cobro ante `PENDING` o `UNKNOWN`. | Escalamiento y regla operativa de la barrera. |
| `operationNumber` | String numérico de 1 a 64 dígitos y único por operación. | Restricciones adicionales, si el procesador las requiere. |
| `additionalFields` | Objeto opcional con valores String. | Claves aceptadas y uso final de cada dato. |
| Códigos del procesador | `00` aprobado; `01` es un ejemplo verificado de rechazo. | Catálogo completo de códigos no aprobados. |
| Cancelación remota | Usa `POST /reversals` con el `operationNumber` original y termina en `CANCELLED`. | Significado y uso de los códigos `14` y `15` en la respuesta HTTP. |
| Extorno | `POST /reversals` y consulta por la misma referencia. | Ventana temporal, ventas liquidadas, doble extorno y semántica de `UNKNOWN` tras un reinicio. |
| Monedas y medios de pago | Para PEN se debe enviar `"604"`. | Monedas y medios habilitados para el comercio. |

## Ambientes

| Ambiente | Objetivo | Salida esperada |
| --- | --- | --- |
| Integración | Validar red, contrato JSON y control de errores. | Cliente compatible con los endpoints y códigos HTTP. |
| UAT | Validar el flujo físico y la política del carril. | Evidencias aprobadas de escenarios normales y de recuperación. |
| Producción | Procesar cobros reales. | Parámetros definitivos registrados, monitoreo y soporte habilitados. |

## Control de cambios

Registra la versión de Pay-me PinPAD y la fecha de vigencia junto con la configuración de cada terminal. Un cambio en rutas, campos, tipos, estados, timeouts o semántica requiere revisar el cliente antes del despliegue.

<Warning>
  Las rutas `/api/v1/payments` y `/api/v1/payments/{operationNumber}`, la respuesta anidada en `result.state` y los códigos locales `P01–P21` pertenecen a documentación anterior. No forman parte del contrato vigente descrito en esta sección.
</Warning>
