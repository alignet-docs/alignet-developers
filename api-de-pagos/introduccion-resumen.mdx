La API de Orquestador de Pay-me permite procesar pagos a través de múltiples métodos y procesadores desde un único endpoint.

Centraliza la autorización, autenticación (3DS) y gestión de riesgo en una sola integración.

## Flujo de integración

<Steps>
  <Step title="Obtén tu Access Token">
    Genera un token usando el endpoint de [Autenticación](/api-de-pagos/autenticacion) con tus credenciales.
  </Step>

  <Step title="Selecciona el módulo">
    Define el flujo que implementarás: PayIn, Recurrentes, Devoluciones u Onboarding.
  </Step>

  <Step title="Ejecuta tu primer request">
    Realiza una operación en ambiente de Pre-Producción.
  </Step>

  <Step title="Procesa la respuesta">
    Evalúa el resultado de la transacción (aprobado, denegado o pendiente).
  </Step>

  <Step title="Configura notificaciones">
    Implementa un endpoint para recibir eventos Server-to-Server.
  </Step>

  <Step title="Pasa a Producción">
    Cambia la Base URL una vez validadas tus pruebas.
  </Step>
</Steps>

## Consideraciones generales

<CardGroup cols={2}>
  <Card title="Montos en centavos" icon="banknote">
    Envía todos los importes en **centavos**. Ejemplo: S/. 10.50 → `"1050"`.
  </Card>

  <Card title="Token temporal" icon="key">
    El **Access Token** tiene duración limitada. Renuévalo antes de su expiración.
  </Card>

  <Card title="Fechas en UTC" icon="clock">
    Todas las fechas del API se manejan en formato **UTC (Unix time)**.
  </Card>

  <Card title="Validación en backend" icon="shield-check">
    Valida siempre la respuesta final de la operación desde tu backend.
  </Card>
</CardGroup>
