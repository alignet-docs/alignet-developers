La API de Orquestador de Pay-me es una solución tecnológica **independiente del procesador** que permite integrar pagos a través de un único punto de conexión, con acceso a una red mundial de procesamiento.

Abarca servicios de orquestación de pagos, evaluación de riesgo y autenticación 3DS en diferentes países.

## Flujo de integración

<Steps>
  <Step title="Obtén tu Access Token">
    Genera un token de acceso usando el [API de Autenticación](/autenticacion) con tus credenciales `client_id` y `client_secret`.
  </Step>
  <Step title="Elige tu módulo">
    Selecciona el módulo que necesitas — [PayIn](/payin/introduccion), [Pagos Recurrentes](/pagos-recurrentes/introduccion), [Devoluciones](/devoluciones/introduccion) u [Onboarding](/onboarding/introduccion).
  </Step>
  <Step title="Realiza tu primera transacción">
    Ejecuta un request en Pre-Producción con los [datos de prueba](/payin/referencia) disponibles.
  </Step>
  <Step title="Valida la notificación">
    Configura tu endpoint para recibir y verificar las [notificaciones Server-to-Server](/payin/notificaciones).
  </Step>
  <Step title="Pasa a Producción">
    Una vez validadas tus pruebas, cambia la Base URL al ambiente de Producción.
  </Step>
</Steps>

## Consideraciones generales

<Note>
  Todos los montos se expresan en **centavos**. Ejemplo: S/. 10.50 → `"1050"`.
</Note>

<Note>
  El Access Token tiene una duración limitada. Renuévalo antes de que expire para evitar errores de autenticación.
</Note>

<Note>
  Todas las fechas devueltas por la API están en formato **UTC** y **Unix time**.
</Note>
