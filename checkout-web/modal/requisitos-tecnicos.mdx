Para realizar la conexión a Wallet y VPOS2 es necesario disponer de los siguientes componentes según el lenguaje de programación utilizado:

<CardGroup cols={2}>
  <Card title="Java">
    - Framework Axis2
    - Framework Jersey
    - jsr311-api-1.0.jar
    - jersey-client-1.0.2.jar
    - jersey-core-1.0.2.jar
    - jersey-server-1.0.2.jar
  </Card>
  <Card title="C# y VB">
    - System.Text
    - System.Security.Cryptography
  </Card>
  <Card title="PHP">
    - PHP5
    - OpenSSL 0.9.7 en adelante
    - HASH
    - OPENSSL
    - XML
    - SOAP
  </Card>
</CardGroup>

<Note>
Las librerías indicadas para JAVA están contenidas en el Kit de Integración.
</Note>
