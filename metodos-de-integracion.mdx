## Clasificación de métodos

- **Web:** Checkout Web (Flex), Checkout Modal
- **E-commerce:** WooCommerce, Prestashop, VTEX
- **Presencial:** POS (Alignet)
- **Mobile:** SDK Mobile
- **Backend:** API de Pagos
