  <Step title="Construir el payload">
    El payload contiene toda la información necesaria para inicializar el formulario. Estructura el objeto según los datos de tu transacción.

    <AccordionGroup>
      <Accordion title="Campos de la transacción">
        | Field | Description | Type | Obligatorio |
        |---|---|---|---|
        | `action` | Acción a ejecutar. Valor: `authorize` | String | SI |
        | `channel` | Canal de la transacción. Valor: `ecommerce` | String | SI |
        | `merchant_code` | Identificador del comercio | String | SI |
        | `merchant_operation_number` | Número de pedido. Entre 6 y 12 dígitos. | String | SI |
        | `payment_details.amount` | Monto en centavos. Ej.: S/. 10.50 → `1050` | String | SI |
        | `payment_details.currency` | Código ISO-3 de la moneda. Ej.: `604` para Soles | String | SI |
        | `payment_details.additional_fields` | Campos personalizados en formato `key:value` | Dictionary | NO |
      </Accordion>

  <Step title="Inicializar el componente">
    Crea una nueva instancia de `FlexPaymentForms` con el **nonce**, el **payload** y opcionalmente los **display_settings**.

    | Campo | Obligatorio | Tipo | Descripción |
    |---|---|---|---|
    | `nonce` | SI | Alfanumérico | Código generado desde el API Nonce. |
    | `payload` | SI | Objeto JSON | Datos de la transacción construidos en el paso anterior. |
    | `display_settings` | NO | Objeto | Configuraciones de visualización del formulario. |
    | `display_settings.methods` | NO | Array de String | Métodos a mostrar: `CARD` / `YAPE` / `QR` / `BANK_TRANSFER` / `CUOTEALO` / `PAGOEFECTIVO`. Si no se envía, se muestran todos los habilitados. |
```javascript
    var paymentForm = new FlexPaymentForms({
        "nonce": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.........",
        "payload": payload,
        "display_settings": {
            methods: ['QR', 'BANK_TRANSFER', 'CARD']
        }
    });
```
  </Step>

  <Step title="Mostrar el formulario">
    Indica en qué **elemento del DOM** se debe renderizar el formulario y define las funciones **callback**.

    <CardGroup cols={3}>
      <Card title="responseCallback" icon="circle-check">
        Se ejecuta cuando el proceso está completado (Autorizado/Denegado).
      </Card>
      <Card title="trackingCallback" icon="chart-line">
        Se ejecuta por cada evento disparado durante el proceso.
      </Card>
      <Card title="onErrorCallback" icon="circle-xmark">
        Se ejecuta cuando hay un error durante el proceso.
      </Card>
    </CardGroup>
```javascript
    function responseCallback(response) {
        console.log("-------Respuesta-------");
        console.log({response});
    }

    function trackingCallback(trackdata) {
        console.log("-------Tracking de Eventos-------");
        console.log({trackdata});
    }

    function onErrorCallback(error) {
        console.log("-------Error en el proceso-------");
        console.log({error});
    }

    paymentForm.init(
        document.querySelector('#demo'),
        responseCallback,
        trackingCallback,
        onErrorCallback
    );
```

    <Note>
    El objeto `response` de la función `responseCallback` tendrá la misma estructura que la respuesta del API de Autorización - ecommerce.
    </Note>
