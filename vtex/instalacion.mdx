Sigue los pasos a continuación para instalar y activar el conector en tu tienda VTEX:

### 1) Instalar VTEX IO CLI

Descarga e instala la CLI de VTEX IO según tu sistema operativo.\
**URL:** _Installing VTEX IO CLI_

### 2) Iniciar sesión en VTEX

Abre una terminal y ejecuta el siguiente comando para iniciar sesión en tu cuenta VTEX:

```text
vtex login
```

El inicio de sesión se realizará con las credenciales de tu tienda VTEX.

### 3) Instalar el conector Payme

En la misma terminal, ejecuta el siguiente comando para instalar el conector:

```text
vtex install acalderom.payme-flex
```

### 4) Validar instalación en el Admin VTEX

1. Ingresa a tu tienda VTEX con tus credenciales.
2. En el menú lateral, dirígete a **App Management**.
3. Verifica que la aplicación **PayMe** se haya instalado correctamente.

<Check>
  Con estos pasos, la aplicación queda disponible en tu entorno VTEX y lista para ser configurada.
</Check>
