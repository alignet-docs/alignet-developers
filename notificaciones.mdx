Pay-me notifica el resultado final de cada transacción enviando un `POST` al endpoint que configures en tu servidor. Esto es especialmente crítico para métodos asíncronos donde el resultado no es inmediato.

---

## ¿Cómo funciona?

<Steps>
  <Step title="Configura tu endpoint">
    Define una URL pública en tu servidor que pueda recibir peticiones `POST` de Pay-me. Compártela con tu asesor comercial para que sea registrada.
  </Step>
  <Step title="Recibe la notificación">
    Pay-me enviará un `POST` con el resultado final de la transacción en formato JSON, incluyendo el estado, el método de pago y los datos de la operación.
  </Step>
  <Step title="Verifica el signature">
    Cada notificación incluye un `signature` en el header generado con `SHA512withRSA`. Debes validarlo con la llave pública de Pay-me antes de procesar la notificación.
  </Step>
  <Step title="Responde con HTTP 200">
    Tu servidor debe responder con `HTTP 200` en un máximo de **10 segundos**. Si Pay-me no recibe esa respuesta reintentará el envío.
  </Step>
</Steps>

---

## Payload de la notificación

### Header

| Campo | Descripción | Tipo |
| :-- | :-- | :-- |
| `signature` | Firma digital para verificar la autenticidad del payload | `String` |

### Body

| Campo | Descripción | Tipo | Obligatorio |
| :-- | :-- | :-- | :-- |
| `success` | Indica si el proceso se realizó correctamente: `true` o `false` | `String` | SI |
| `merchant_code` | Identificador del comercio | `String` | SI |
| `merchant_operation_number` | Número de pedido de la operación | `String` | SI |
| `transaction.transaction_id` | Identificador único de la transacción | `String` | SI |
| `transaction.state` | Estado: `AUTORIZADO`, `DENEGADO`, `INVALIDO` | `String` | SI |
| `transaction.currency` | Código ISO 4217 de la moneda | `String` | SI |
| `transaction.amount` | Monto en centavos | `String` | SI |
| `transaction.processor_response` | Resultado detallado del procesamiento — varía según el método de pago | `Object` | NO |
| `meta.status.code` | Código de resultado del flujo | `String` | SI |
| `meta.status.message_ilgn.[].value` | Mensaje del resultado | `String` | SI |

## Verificación del signature

El `signature` es una firma digital generada por Pay-me usando el algoritmo `SHA512withRSA` con una llave privada RSA de 2048 bits. Debes verificarla usando la llave pública correspondiente a tu ambiente.

<Warning>
  **Nunca proceses una notificación sin verificar el signature.** Un signature inválido indica que la petición no proviene de Pay-me o que el contenido fue modificado en tránsito.
</Warning>

### Especificaciones técnicas

| Propiedad | Valor |
| :-- | :-- |
| Tipo de llave | Asimétrica |
| Especificación | RSA\_2048 |
| Longitud | 2048 bits |
| Uso | Firma y verificación |
| Algoritmo | `SHA512withRSA` |
| Longitud del signature | Hasta 512 caracteres |

### Pasos de verificación

<Steps>
  <Step title="Identifica el campo a cifrar">
    El campo a verificar depende del flujo:

    - **Notificación S2S** — el `body` completo de la petición recibida.
    - **Redirección** — el parámetro `authorization_result` (JSON en Base64) recibido en la URL de retorno.
  </Step>
  <Step title="Decodifica el signature">
    El `signature` viene en Base64 — decodifícalo antes de usarlo en la verificación.
  </Step>
  <Step title="Verifica con la llave pública">
    Usa la llave pública del ambiente correspondiente para verificar que el signature coincide con el campo identificado en el paso 1.
  </Step>
</Steps>

### Ejemplo de verificación en Python

```python
import json
import base64
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.serialization import load_pem_public_key

def verify_rsa_signature(public_key_pem, authorization_result, signature):
    public_key = load_pem_public_key(public_key_pem.encode('utf-8'))
    message_bytes = authorization_result.encode('utf-8')
    try:
        public_key.verify(
            signature,
            message_bytes,
            padding.PKCS1v15(),
            hashes.SHA512()
        )
        return True
    except Exception:
        return False

if __name__ == "__main__":
    public_key_pem = ""  # Llave pública del ambiente
    signature = base64.b64decode("SIGNATURE")
    message = ""  # Body de la notificación S2S o authorization_result en redirección
    result = verify_rsa_signature(public_key_pem, message, signature)
    print(f'Firma válida: {result}')
```

## Reintentos

Pay-me espera **10 segundos** para recibir un `HTTP 200`. Si no lo recibe reintentará el envío según la configuración del comercio:

| Intento | Tiempo de espera |
| :-- | :-- |
| 1° reintento | 1 minuto |
| 2° reintento | 5 minutos |
| 3° reintento | 30 minutos |

<Note>
  El número de reintentos es configurable por comercio. Si agotados los reintentos tu servidor sigue sin responder, usa el [API de Consulta](/payin/consulta) para verificar el estado manualmente.
</Note>
