## Resumen de Operación

<CardGroup cols={3}>
  <Card title="Éxito" color="#2ecc71" icon="check">
    Código **00**. Única respuesta que permite la entrega del bien o servicio.
  </Card>

  <Card title="Reintentar" color="#3498db" icon="rotate">
    Códigos **19, 21, 25, 28**. Problemas temporales; se sugiere reintentar la transaccion.
  </Card>

  <Card title="Denegado" color="#e74c3c" icon="xmark">
    Cualquier otro código. No entregar producto; solicitar otro medio de pago (No reintentar).
  </Card>
</CardGroup>

## Códigos de Acción Inmediata

Estos códigos representan el 90% de las interacciones. Protagoniza estos en tu lógica de negocio.

| Código | Mensaje de Retorno | Estado | Acción Sugerida |
| :-- | :-- | :-- | :-- |
| **00** | Pago Exitoso | <span style={{color: '#2ecc71'}}>**EXITOSO**</span> | Proceder con la entrega del producto/servicio. |
| **19** | Reintentar la transacción | <span style={{color: '#3498db'}}>**REINTENTAR**</span> | Problema de comunicación. Intentar nuevamente. |
| **21** | Reintentar la transacción | <span style={{color: '#3498db'}}>**REINTENTAR**</span> | Problema de comunicación. Intentar nuevamente. |
| **25** | Reintentar la transacción | <span style={{color: '#3498db'}}>**REINTENTAR**</span> | Problema de comunicación. Intentar nuevamente. |
| **28** | Reintentar la transacción | <span style={{color: '#3498db'}}>**REINTENTAR**</span> | Problema de comunicación. Intentar nuevamente. |
| **51** | Fondos insuficientes | <span style={{color: '#e74c3c'}}>**DENEGADO**</span> | Solicitar al cliente usar otra tarjeta. |
| **54** | Tarjeta expirada | <span style={{color: '#e74c3c'}}>**DENEGADO**</span> | Solicitar actualización de datos de tarjeta. |
