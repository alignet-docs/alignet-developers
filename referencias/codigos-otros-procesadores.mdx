### Comparativa de Códigos Críticos

Los errores más comunes mapeados entre ambos procesadores para tu lógica de frontend.

| Evento | Código Niubiz | Código Izipay | Acción Sugerida |
| :-- | :-- | :-- | :-- |
| **Aprobado** | `000` | `00` | Proceder con la venta. |
| **Tarjeta Vencida** | `101` | `54` | Pedir otra tarjeta o revisar fecha. |
| **Saldo Insuficiente** | `116` | `51` | Sugerir otro medio de pago. |
| **PIN Incorrecto** | `117` | `55` | Solicitar reingreso de clave. |
| **Sospecha Fraude** | `102` | `59` | Bloqueo de seguridad. No entregar. |
| **CVV Incorrecto** | `129` | `82` | Revisar código de seguridad. |
