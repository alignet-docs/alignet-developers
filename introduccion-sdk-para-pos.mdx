Bienvenido a la guía de integración de **Pay-me POS SDK**.

Este SDK permite a las aplicaciones Android integrarse con los dispositivos POS compatibles con Pay-me para realizar operaciones de pago presenciales de forma segura y estandarizada. A través de sus funcionalidades, es posible ejecutar autorizaciones de pago, consultas de transacciones, extornos e impresión de comprobantes directamente desde la aplicación integradora.

La presente documentación describe los requisitos necesarios para la integración, la configuración inicial del SDK y los flujos disponibles para interactuar con los servicios de Pay-me POS.

## Funcionalidades Disponibles

Pay-me POS SDK permite integrar las siguientes funcionalidades dentro de una aplicación Android:

- **Autorización de Pagos:** Procesamiento de transacciones mediante tarjeta o código QR.
- **Consulta de Transacciones:** Consulta del estado y detalle de operaciones realizadas.
- **Extornos:** Reversión de transacciones utilizando el número de operación.
- **Impresión de Comprobantes:** Generación e impresión de vouchers desde el dispositivo POS.
