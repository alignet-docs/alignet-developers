Usa este checklist para revisar el SDK antes de solicitar validación final.

## 1. Preparación

- Plataforma objetivo definida: **Android**, **iOS** o ambas.
- Requisitos técnicos revisados por plataforma.
- Credenciales y ambiente de pruebas disponibles.
- Caso de uso definido: cobro, afiliación o ambos.

## 2. Implementación del SDK

- SDK instalado correctamente en el proyecto.
- Inicialización completada sin errores.
- Parámetros de entrada y salida validados.
- Manejo de errores implementado en la app.

## 3. Flujo funcional

- Flujo de cobro aprobado probado correctamente.
- Respuesta rechazada o error controlado validado.
- Flujo de afiliación probado si aplica.
- Navegación y experiencia del usuario revisadas.

## 4. Calidad técnica

- Logs disponibles para diagnóstico.
- Validación de versiones y dependencias completada.
- Datos sensibles no expuestos en cliente.
- Manejo de reintentos y estados previsto.

## 5. Validación final

- Sandbox ejecutado con evidencia de pruebas.
- Casos críticos revisados con el equipo.
- Build lista para ambiente productivo.
- Integración lista para despliegue.
