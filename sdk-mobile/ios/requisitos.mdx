Antes de iniciar la integración, confirma que el comercio y el proyecto iOS cumplen las condiciones mínimas para usar Pay-me SDK.

<Info>
  Solicita al equipo de integraciones las credenciales, SDKs, métodos de pago habilitados y ambiente asignado para tus pruebas.
</Info>

## Requisitos de negocio

<CardGroup cols={2}>
  <Card title="Entidad legal" icon="building">
    Razón social registrada, RUC activo y datos comerciales validados.
  </Card>

  <Card title="Presencia digital" icon="globe">
    Aplicación, web o canal digital asociado al comercio.
  </Card>

  <Card title="Seguridad" icon="lock">
    Canales protegidos y manejo seguro de credenciales, tokens y respuestas de pago.
  </Card>

  <Card title="Cuenta bancaria" icon="banknote">
    Cuenta bancaria a nombre de la razón social del comercio.
  </Card>
</CardGroup>

## Requisitos técnicos iOS

<AccordionGroup>
  <Accordion title="Plataforma" icon="mobile-screen-button" defaultOpen>
    - iOS 13.0 o superior.
    - Xcode 14.2 o superior.
    - Swift 5.5 o superior.
    - Proyecto iOS con soporte para frameworks dinámicos.
  </Accordion>

  <Accordion title="Conectividad y configuración" icon="wifi">
    - Conectividad a internet disponible durante el flujo.
    - Configuración de red y permisos revisados en el proyecto.
    - Validación de estado de red antes de iniciar el SDK.
  </Accordion>

  <Accordion title="Backend del comercio" icon="server">
    - Consumo del API de Seguridad para generar `Access Token`.
    - Manejo seguro de credenciales fuera de la app.
    - Registro de operación único por intento de pago.
    - Confirmación final del resultado desde backend cuando aplique.
  </Accordion>
</AccordionGroup>

## Consideraciones de entorno

<Note>
  El ambiente sandbox está disponible para pruebas controladas. Para pruebas con simuladoras o métodos específicos, coordina la disponibilidad con el equipo de integraciones.
</Note>

<Note>
  Todas las horas operativas indicadas para soporte o coordinación se consideran en GMT-5 (Perú).
</Note>

<Warning>
  No expongas credenciales, tokens ni información sensible en la app móvil, repositorios, logs o herramientas de analítica.
</Warning>
