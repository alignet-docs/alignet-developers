Pay-me SDK iOS permite integrar flujos de **cobro** y **afiliación** directamente en tu aplicación móvil, manteniendo una experiencia nativa para el usuario final.

<Info>
  La integración debe coordinarse con el equipo de integraciones para recibir SDKs, credenciales, ambiente y métodos de pago habilitados para tu comercio.
</Info>

## ¿Qué puedes integrar?

<CardGroup cols={2}>
  <Card title="Cobros móviles" icon="credit-card">
    Inicializa el SDK para procesar pagos con los métodos habilitados para el comercio.
  </Card>

  <Card title="Afiliaciones" icon="user-plus">
    Registra o actualiza datos asociados a flujos de afiliación cuando aplique al negocio.
  </Card>

  <Card title="Métodos de pago" icon="wallet">
    Tarjetas, Yape, QR, transferencia bancaria, Cuotéalo y PagoEfectivo según configuración.
  </Card>

  <Card title="Sandbox" icon="flask">
    Valida escenarios controlados antes de solicitar salida a producción.
  </Card>
</CardGroup>

## Ruta sugerida

<Steps>
  <Step title="Revisa requisitos">
    Confirma versiones, frameworks, permisos y prerequisitos de negocio en [Requisitos SDK iOS](/sdk-mobile/ios/requisitos).
  </Step>

  <Step title="Instala el SDK">
    Agrega los frameworks entregados por Pay-me, configura Xcode y valida embedding desde [Instalación](/sdk-mobile/ios/instalacion).
  </Step>

  <Step title="Implementa el flujo">
    Inicializa `PaymeClient`, configura el ambiente y envía el objeto de request para cobro o afiliación.
  </Step>

  <Step title="Captura la respuesta">
    Implementa los delegates del SDK para procesar resultado final, eventos, cancelaciones y errores.
  </Step>

  <Step title="Valida en sandbox">
    Ejecuta pruebas con [Datos de prueba](/pagos/datos-de-prueba) antes de pedir validación final.
  </Step>
</Steps>
